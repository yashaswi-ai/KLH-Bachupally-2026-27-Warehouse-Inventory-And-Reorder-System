# Warehouse Inventory and Reorder System

## 1. Introduction

The Warehouse Inventory and Reorder System is designed to manage products and monitor stock levels in a warehouse. The system helps identify products that have reached or fallen below their reorder level.

## 2. Problem Statement

Managing warehouse inventory manually can make it difficult to track stock quantities and identify products that need to be reordered. This project provides a simple system to organize inventory information and monitor stock levels.

## 3. Objectives

- Maintain product details.
- Track available quantities.
- Store reorder levels.
- Identify low-stock products.
- Provide reorder information.
- Reduce manual inventory management.

## 4. Functional Requirements

- Add a new product.
- View product details.
- Search for a product.
- Update product quantity.
- Set a reorder level.
- Check stock status.
- Identify products requiring reorder.

## 5. Non-Functional Requirements

- The system should be simple to use.
- The system should provide accurate inventory information.
- The system should be easy to maintain.
- The system should provide clear output.

## 6. Technology Requirements

- Java
- Visual Studio Code
- Git
- GitHub

## 7. Expected Outcome

The system should allow users to manage warehouse inventory and identify products that require replenishment based on their available quantity and reorder level.
