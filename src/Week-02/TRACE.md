# Week 2 - Trace Table

## Test Case 1 - Laptop

| Step | Product ID | Product Name | Quantity | Unit Price | Subtotal | Handling Fee | Total Value |
|---|---:|---|---:|---:|---:|---:|---:|
| 1 | 101 | Laptop | 5 | 50000 | - | - | - |
| 2 | 101 | Laptop | 5 | 50000 | 250000 | 12500 | 262500 |

### Calculation

Subtotal = 5 × 50000 = 250000

Handling Fee = 250000 × 0.05 = 12500

Total Value = 250000 + 12500 = 262500
