# Week 4 - Iteration

## Objective

To implement iteration in Java using loops, counters, flags, break statements, and a sentinel-controlled menu for the warehouse inventory system.

## Concepts Used

- while loop
- for loop
- for-each loop
- Counter
- Flag variable
- break statement
- Sentinel-controlled loop
- Search
- Repeated menu execution

## Procedure

1. Start the Java program.
2. Create a Scanner object to read user input.
3. Initialize the menu choice.
4. Use a while loop to repeatedly display the inventory menu.
5. Continue displaying the menu until the user selects option 5.
6. Use if-else statements to process the selected menu option.
7. For stock checking, compare quantity with the reorder level.
8. Use a while loop and counter to count the number of products.
9. Store sample product IDs in an integer array.
10. Use a for-each loop to search for a product ID.
11. Use a boolean flag to record whether the product was found.
12. Use break to stop searching once the product ID is found.
13. Use a for loop to display numbers from 1 to 5.
14. Display an exit message when the user selects option 5.
15. Close the Scanner and terminate the program.

## Expected Outcome

The program should repeatedly display the menu, perform the selected inventory operation, search product IDs, demonstrate different loop types, and terminate when the user selects the Exit option.
