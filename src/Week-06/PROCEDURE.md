# Week 6 - Arrays

## Objective

To use one-dimensional and two-dimensional arrays for storing, searching, counting, and processing warehouse inventory data.

## Procedure

1. Create a Java class named `InventoryWeek06`.
2. Create one-dimensional arrays to store product IDs and quantities.
3. Traverse the arrays using a `for` loop.
4. Search for a product ID using array traversal.
5. Find the maximum stock quantity.
6. Find the minimum stock quantity.
7. Count the number of low-stock products.
8. Create a two-dimensional array to represent warehouse sections.
9. Traverse the two-dimensional array using nested loops.
10. Display all calculated inventory information.
11. Compile and execute the program using Java.
