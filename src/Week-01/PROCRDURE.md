# Week 1 - Procedure

## Title

From Problem to Program - Warehouse Inventory and Reorder System

## Objective

To convert a warehouse inventory problem into a precise specification and implement a simple Java program using input, processing, and output.

## Problem

The system records a product's ID, name, quantity, and reorder level. It determines whether the product needs to be reordered.

## Inputs

- Product ID
- Product Name
- Quantity
- Reorder Level

## Process

1. Read the product details.
2. Display the product details.
3. Compare the quantity with the reorder level.
4. If quantity is less than or equal to the reorder level, mark the product as requiring reorder.
5. Otherwise, mark the product as having sufficient stock.

## Output

The program displays the product information and stock status.

## Algorithm

1. Start.
2. Read Product ID.
3. Read Product Name.
4. Read Quantity.
5. Read Reorder Level.
6. Compare Quantity with Reorder Level.
7. If Quantity <= Reorder Level, display "Reorder Required".
8. Otherwise, display "Stock Available".
9. Stop.

## Concepts Used

- Input and output
- Variables
- Primitive data types
- Scanner
- Conditional statement
- Input-process-output model
- Algorithm design
