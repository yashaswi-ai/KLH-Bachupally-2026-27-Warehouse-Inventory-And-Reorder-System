# Week 5 - Methods and Recursion

## Objective

To apply methods, method overloading, scope, parameters, return values, and recursion to the warehouse inventory system.

## Procedure

1. Create a Java class named `InventoryWeek05`.
2. Import the `Scanner` class for user input.
3. Create a method to display the program heading.
4. Create a method `checkStock()` to determine the stock status.
5. Create an overloaded `calculateValue()` method to calculate inventory value.
6. Create a recursive method `totalQuantity()` to demonstrate recursion.
7. Read product ID, product name, quantity, reorder level, and unit price.
8. Call the required methods using the entered values.
9. Display the product details, stock status, inventory value, and recursive calculation.
10. Compile and execute the program using the Java compiler and JVM.
