# Week 7 - Objects and Classes

## Objective

To apply object-oriented programming concepts to the Warehouse Inventory System using classes, objects, constructors, encapsulation, instance methods, `toString()`, and composition-style modelling.

## Procedure

1. Create a `Product` class with product ID, product name, quantity, and price.
2. Declare the product fields as private to implement encapsulation.
3. Create a constructor to initialize product details using the `this` keyword.
4. Define getter methods to retrieve product information.
5. Create a `setQuantity()` method to update quantity while preventing negative values.
6. Create a `calculateValue()` method to calculate the total value of a product's stock.
7. Override `toString()` to display product details in a readable format.
8. Create an `Inventory` class that contains a `Product` object and a warehouse name.
9. Create product objects and associate them with different warehouses.
10. Display the product information and total stock value.
11. Update the laptop quantity and display its updated stock value.
12. Compile and execute the program using Java.
